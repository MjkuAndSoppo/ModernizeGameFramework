用户说"run"，意思是运行客户端来测试刚才的修改。需要启动Minecraft客户端来验证更改。
用户说"输出"，意思是输出一份版本到“build\libs\“目录下，注意版本迭代和提交更新日志.md文件，不清理旧版本.jar文件。
所有的代码注释都必须是中文。
所有的主要功能可通过命令开关如：“/<项目名称> <主要功能名称> on/off“ 来开启或关闭。
每次做出改动后都需要"run"。
如果用户输入过于简洁就用trae的提问面板向用户提问问题细节5~10个问题，必须！。
每次做出改动后都需要将改动内容（提交内容、修复内容、修改时间）记录到根目录的“更新日志.md”（没有则创建），让用户可以溯源。
最后用trae的提问面板向用户确认任务是否完成，必须！
